הערה כללית: כל התפקידים הייחודיים (רכזת תקשוב, אב הבית וכו') חייבים להיות מוגדרים מראש על ידי מנהלת / סגנית / מזכירה במערכת ההרשאות. כל המסכים מותאמים מובייל במלואם.


============================================================
חלק א' – מערכת רכש
============================================================

1. סקירה כללית

מערכת לניהול בקשות רכש של מורות, אישור המנהלת, העברה למזכירה לביצוע הרכישה, ומעקב אחר הגעת הציוד. כולל גם מסלול של רכישה עצמית אצל ספק של בית הספר עם קוד אישור.

------------------------------------------------------------

2. משתמשים והרשאות

מורה:
• הגשת בקשות רכש
• מעקב סטטוס
• בקשה לרכישה עצמית

מנהלת:
• אישור / דחייה פרטנית לכל פריט בבקשה
• הוספת הערות
• מתן קוד אישור לרכישה עצמית

מזכירה:
• קבלת בקשות מאושרות
• ביצוע הרכישה
• עדכון "הגיע"
• ניהול ספקים

------------------------------------------------------------

3. הגשת בקשת רכש (מורה)

המורה ממלאת טופס:

• מטרת הבקשה (שדה חופשי) – חובה
• רשימת פריטים – ניתן להוסיף כמה שורות שרוצים. לכל פריט:
  - שם הפריט
  - כמות
  - מחיר משוער (אופציונלי)
  - קישור לחנות (אופציונלי)
  - הערה (אופציונלי)
• רמת דחיפות: רגיל / דחוף / מיידי
• תאריך יעד (אופציונלי)
• סוג בקשה:
  - רכישה רגילה (המזכירה תבצע)
  - בקשה לרכישה עצמית

------------------------------------------------------------

4. אישור מנהלת – אישור פרטני לכל פריט

• ✅ אישור פריט
• ❌ דחיית פריט + הערה (חובה)
• הערה כללית לכל הבקשה

סטטוסים: "מאושרת חלקית" / "מאושרת" / "נדחתה"
התראות: למזכירה (רשימת פריטים מאושרים), למורה (החלטה + הערות)

------------------------------------------------------------

5. ביצוע הרכישה (מזכירה)

• רשימת בקשות מאושרות לפי דחיפות
• לכל פריט: ✅ "הגיע"
• כשפריט מסומן "הגיע" – התראה למורה

------------------------------------------------------------

6. רכישה עצמית

1. מורה ממלאת טופס + "רכישה עצמית" + בחירת ספק
2. מנהלת מאשרת פרטנית
3. אם אושר – קוד אישור ייחודי (PRCH-YYYY-XXXX)
4. המורה מציגה קוד לספק
5. התראה למזכירה

------------------------------------------------------------

7. ניהול ספקים (מזכירה / מנהלת)

• שם, כתובת/טלפון, סוג ציוד, הערות

------------------------------------------------------------

8. דוחות

מנהלת: סך הוצאות, אישורים/דחיות, זמן ממוצע, פילוח לפי ספק, ייצוא Excel


============================================================
חלק ב' – מערכת תחזוקה (אב בית)
============================================================

1. סקירה כללית

דיווח ליקויי תחזוקה פיזיים. מורה מדווחת, מנהלת מעבירה לאב הבית, מעקב תיקון.

------------------------------------------------------------

2. משתמשים והרשאות

מורה: דיווח + מעקב
מנהלת: קבלה, העברה לאב הבית, עדיפויות
אב הבית: קבלת משימות, סימון "בוצע"

------------------------------------------------------------

3. דיווח על ליקוי (מורה)

• מיקום (רשימה נפתחת + "אחר")
• סוג: חשמל/תאורה, אינסטלציה, ריהוט שבור, דלת/חלון, ניקיון, ציוד חצר, אחר
• תיאור מפורט
• צירוף תמונה (אופציונלי)
• דחיפות: רגיל / דחוף / סכנה בטיחותית

------------------------------------------------------------

4. זרימת הטיפול

מורה → מנהלת (התראה) → אב הבית → בוצע → מורה (התראה)

------------------------------------------------------------

5. סטטוסים

🟡 חדש | 🔵 הועבר לאב הבית | 🟠 בתהליך | ⏸️ ממתין לחלקים | ✅ תוקן | ❌ נסגר

------------------------------------------------------------

6. פעולות

מנהלת: העברה לאב הבית / בקשת הבהרה / סגירה ללא טיפול
אב הבית: בוצע (+ תמונה) / בהמתנה + הערה / הוספת הערה

------------------------------------------------------------

7. דוחות

ליקויים פר חודש/קטגוריה/מיקום, זמן תיקון ממוצע, ליקויים חוזרים, ייצוא Excel


============================================================
חלק ג' – מערכת תחזוקת מחשבים (תקשוב)
============================================================

1. סקירה כללית

תקלות מחשבים, מקרנים, ציוד דיגיטלי. התראה משולשת: מנהלת + סגנית + רכזת תקשוב.

------------------------------------------------------------

2. משתמשים והרשאות

מורה: דיווח תקלה
מנהלת, סגנית, רכזת תקשוב: קבלה במקביל, "אני מטפלת" – ראשונה שלוחצת לוקחת

------------------------------------------------------------

3. טופס דיווח (קצר ומהיר)

• מיקום: כיתה / מספר מחשב נייד / מיקום אחר
• סוג: לא נדלק / אינטרנט / מקרן / סאונד / תוכנה / סיסמה / הרשאות / אחר
• תיאור
• תמונה (אופציונלי)
• דחיפות: דחוף (עכשיו) / רגיל (עד מחר)

------------------------------------------------------------

4. זרימת הטיפול

התראה לשלושתן במקביל → "אני מטפלת" → בטיפול → נפתר/הועבר לטכנאי

------------------------------------------------------------

5. פעולות

"אני מטפלת" / "בטיפול" / "הועבר לטכנאי חיצוני" + שם + תאריך / "נפתר" + תיאור / "לא ניתן לתקן"

------------------------------------------------------------

6. צ'אט בתוך הדיווח

שיחה מהירה בין מורה למטפלת — תיעוד + חסכון בשיחות טלפון

------------------------------------------------------------

7. סטטוסים

🟡 דווח | 🔵 בטיפול | 🟠 הועבר לטכנאי | ✅ נפתר | ❌ לא ניתן לתקן

------------------------------------------------------------

8. רישום ציוד (רכזת תקשוב)

• מחשבים נייחים פר כיתה
• מחשבים ניידים (מספר סידורי + מיקום)
• מקרנים / לוחות חכמים
• ציוד ניוד
• היסטוריית תקלות פר יחידה

------------------------------------------------------------

9. דוחות

תקלות פר חודש/סוג/מיקום, זמן תיקון ממוצע, ציוד עם תקלות חוזרות, מי טיפלה הכי הרבה, ייצוא Excel


============================================================
נקודות משותפות
============================================================

• תלות בהגדרת תפקידים: רכזת תקשוב, אב הבית — מוגדרים מראש במערכת ההרשאות
• מובייל-first: במיוחד תחזוקה — מורה מדווחת באמצע שיעור עם תמונה
• התראות רב-ערוצי: Push + מייל + WhatsApp
• היסטוריה מלאה: כל דיווח ופעולה נשמרים ללוג
