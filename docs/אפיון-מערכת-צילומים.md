# אפיון מערכת צילומים והדפסות

> **גרסה:** 1.0 · **עדכון אחרון:** אפריל 2026

---

## א. סקירה כללית

מערכת דיגיטלית לניהול בקשות צילום והדפסה בבית הספר, המחברת בין המורות המגישות בקשות, המנהלת המאשרת, והמזכירה המבצעת. פועלת במובייל ובדסקטופ, כוללת ניהול סטטוסים, התראות אוטומטיות, דוחות ומכסות אופציונליות.

**עקרונות מנחים:** פשטות, גמישות מלאה למנהלת, שקיפות סטטוסים, ללא אחסון קבצים ממושך, מובייל-first.

---

## ב. משתמשים והרשאות

| תפקיד | הרשאות |
|---|---|
| **מורה** | הגשה, צפייה בבקשות שלה, שכפול בקשה, ביטול בקשה ממתינה |
| **מנהלת / סגנית** | אישור / דחייה / השהיה / ביטול אישור · ניהול מכסות · דוחות מלאים |
| **מזכירה** | קבלת התראות · הדפסה בפועל · סימון הושלם |

## ג. שדות טופס הגשת בקשה

| שדה | סוג | חובה |
|---|---|---|
| קובץ PDF | קובץ (מקסימום 20MB) | כן |
| מקצוע | טקסט | כן |
| כיתה | טקסט | כן |
| נושא השיעור | טקסט | כן |
| כמות עותקים | מספר | כן |
| עמודים בקובץ | מספר | כן |
| גודל נייר | A4 / A3 | כן |
| צבע | שחור-לבן / צבעוני | כן |
| סוג נייר | רגיל / בריסטול | כן |
| דו-צדדי | checkbox | לא |

## ד. סטטוסים ומחזור חיי הבקשה

```
נוצרה → pending → [held] → approved → [approval_cancelled] → printing → completed
                ↓
             rejected
```

| סטטוס | תיאור | צבע |
|---|---|---|
| `pending` | ממתינה לאישור | צהוב |
| `held` | בהמתנה זמנית | סגול |
| `approved` | מאושרת | ירוק |
| `approval_cancelled` | אישור בוטל | כתום |
| `printing` | בהדפסה | כחול |
| `completed` | הושלמה | אפור |
| `rejected` | נדחתה (עם סיבה) | אדום |
| `cancelled` | בוטלה על ידי המורה | אפור |

---

## ה. פעולות המנהלת

| פעולה | מתאפשרת כאשר | תוצאה |
|---|---|---|
| **אשר** | pending / held / approval_cancelled | → approved + הודעה למורה |
| **השהה** | pending | → held + הודעה למורה |
| **דחה** | pending / held | → rejected + הודעה עם סיבה |
| **בטל אישור** | approved (לפני הדפסה) | → approval_cancelled + הודעה למורה + הודעה למזכירה |

---

## ו. תהליך ההדפסה (מזכירה)

- בקשות מאושרות מוצגות ממוינות לפי דחיפות (מיידי → דחוף → רגיל)
- לחיצת "הדפס" — פותחת ישירות את ה-PDF להדפסה
- לחיצת "בוצע" — סימון completed + התראה אוטומטית למורה "הדפים שלך מוכנים לאיסוף"
- בחירה מרובה לעדכון bulk status

---

## ז. מערכת מכסות (אופציונלית)

> **סטטוס מימוש:** מוגדר באפיון, ממתין למימוש

- **מתג**: הפעלה/ביטול בהגדרות מערכת
- **כשכבוי**: ללא מגבלת כמות
- **כשפעיל**: מכסה חודשית (אחידה / פר מורה / פר סוג נייר)
- **תצוגה למורה**: מד התקדמות + התראה ב-80% וב-100%
- **בקשת הגדלה**: טופס קצר (כמות + סיבה) → אישור/דחייה על ידי מנהלת

## ח. התראות אוטומטיות

| אירוע | מקבל | ערוץ |
|---|---|---|
| בקשה חדשה | מנהלת + מזכירה | WhatsApp / מייל / in-app |
| אושרה | מורה | WhatsApp / מייל / in-app |
| הושהתה | מורה | WhatsApp / מייל / in-app |
| נדחתה | מורה | WhatsApp / מייל / in-app |
| אישור בוטל | מורה + מזכירה | WhatsApp / מייל / in-app |
| הושלמה | מורה | WhatsApp / מייל / in-app |

כל ההתראות נשלחות דרך `notify()` — WhatsApp אם יש טלפון, אחרת מייל, תמיד in-app.

## ט. דוחות

### מורה
- היסטוריית בקשות עם סטטוסים
- שכפול בקשות קודמות

### מנהלת / מזכירה
- טבלת מעקב מפורטת לפי מורה → כיתה → מקצוע
- ייצוא Excel עם כל השדות
- סה״כ דפים

## י. נקודות טכניות

- **Entity:** `PrintRequest` (school-scoped Firestore)
- **שדות חדשים** (גרסה 1.0): `lesson_topic`, `paper_type`, `binding`, `urgency_level`
- **ללא אחסון ממושך:** PDF נמחק מהמערכת לאחר השלמת ההדפסה (כרגע: מסומן completed, המחיקה ידנית)
- **מובייל-first:** כל הכרטיסים רספונסיביים
- **ייצוא:** Excel דרך ספריית `xlsx` (כבר מותקנת)
