============================================================
Smart Base — אפיון מערכת מלא
מסמך אפיון פונקציונלי | גרסה 1.0 | עדכון 22.4.2026
============================================================

מערכת ניהול בית ספר דיגיטלית, מבוססת ענן, מרובת שוכרים (multi-tenant).
כל בית ספר מבודד לחלוטין — school_id מסופק בהתחברות.
כל המסכים מותאמים מובייל במלואם.


============================================================
חלק א' — ארכיטקטורה טכנית
============================================================

פרונטאנד:
  React 18 + Vite + TailwindCSS + Radix UI
  React Query (tanstack) לכל ה-data fetching
  Lucide icons | Framer Motion | Recharts לגרפים
  XLSX לייצוא Excel | jsPDF לייצוא PDF

בקאנד / מסד נתונים:
  base44 — BaaS מבוסס Firebase Firestore
  Firestore REST API דרך לקוח מותאם (firebaseClient.js)
  אימות: email+password דרך base44.auth

פונקציות שרת (Deno Edge Functions):
  morningDutyReminder    — cron יומי 07:00 ישראל
  createAbsenceNotification
  createPurchaseNotification
  createMaintenanceNotification
  createTechTicketNotification
  createPrintNotification
  checkBirthdays
  checkMissingCertificates
  generatePurchaseApproval
  whatsappBot (WATI)

פריסה:
  surge.sh (static hosting) — teardown+redeploy לניקוי CDN cache

ישויות מרכזיות (Entities):
  User, Notification, Absence, DutyAssignment, DutyType
  PrintRequest, RoomBooking, Room, Equipment, EquipmentBooking
  JournalEntry, Task, Announcement, Event
  MaintenanceTicket, PurchaseRequest, Supplier
  InstitutionSettings, Schedule, Onboarding
  WhatsAppSession, Birthday

חלק ז' — היעדרויות (Attendance)
============================================================

דיווח היעדרות (מורה):
  תאריך התחלה + סיום
  סיבה: ילד חולה / יום בחירה / יום הצהרה / אחר
  צירוף אישור רפואי (קובץ)

זרימת אישור:
  מורה → pending → מנהלת (אישור / דחייה / ממתין לאישור רפואי)

סטטוסים:
  pending | approved | rejected | awaiting_certificate

בוט WhatsApp (WATI):
  דיווח היעדרות דרך WhatsApp בצ'אט שיחה
  שלבים: תאריך התחלה → תאריך סיום → סיבה → אישור
  בדיקת סטטוס היעדרויות קיימות

דיווח למשרד החינוך:
  סימון "דווח למשרד" + מילוי ממלאת מקום

תזכורות:
  checkMissingCertificates — שולחת מייל לממתינות לאישור רפואי

חלק ח' — מערכת צילומים (Printing)
============================================================

הגשת בקשה (מורה):
  קובץ PDF + כיתה + מקצוע + נושא
  עותקים, גודל דף (A4/A3/A5), צבע/שחלב, דו-צדדי
  סוג נייר (רגיל/כבד/מצולם/שקף), כריכה
  דחיפות: רגיל / דחוף / מיידי
  שכפול בקשה קודמת ("בקשה דומה")

אישור מנהלת:
  אישור / דחייה / השהיה זמנית
  ביטול אישור לפני הדפסה
  אישור רב-בקשות בבת אחת (checkbox selection)
  מיון לפי דחיפות + תאריך

ביצוע מזכירה / photo_manager:
  רשימה ממוינת לפי דחיפות
  סימון "בהדפסה" / "הושלם"

מכסות:
  מתג הפעלה/כיבוי (מנהלת)
  מכסה חודשית אחידה
  override פר מורה
  מד התקדמות ויזואלי
  חסימה בהגעה ל-100% + התראה ב-80%
  בקשת הגדלת מכסה + אישור/דחייה

סטטוסים:
  pending | approved | rejected | on_hold | printing | completed | cancelled

דוחות:
  סיכום פר מורה (כמות דפים)
  ייצוא Excel מלא

חסר:
  מכסה פר סוג (צבעוני/בריסטול)
  גרפים השוואה בין מורות
  מחיקת PDF אחרי הדפסה

❌ חסר: ~15 פונקציות

פונקציות חסרות לפי עדיפות:

נמוכה (פשוטות לביצוע):
  — מכסה פר סוג הדפסה

בינונית:
  — גרפים + פילוח מפורט בצילומים
  — תצוגה מאוחדת כל חדרים בטבלה
  — % תפוסה שבועי/חודשי בחדרים
  — צירוף תמונה לדיווח תחזוקה
  — דוחות תחזוקה (מיקום/קטגוריה/חודש)
  — ליקויים חוזרים באותו מיקום
  — מאגר ציוד דיגיטלי
  — דוחות תקשוב
  — דוחות רכש

תלוי תשתית:
  — מחיקת PDF אחרי הדפסה
